# 课程与教师评价平台

面向学生的课程反馈平台，收集真实课堂体验，为学弟学妹提供客观参考。

---

## 📋 项目定位

本项目是**教师/课程评价 Web 网站**，不是 App、小程序、桌面端或浏览器插件。

## 📍 当前阶段：Phase 1 Mock Frontend

本项目目前处于 **Phase 1：前端原型版**，**核心功能已完成并通过最终验收**。

> **重要声明：**
> - 当前没有真实登录系统
> - 当前没有真实数据库
> - 当前没有真实学校、真实教师、真实学生数据
> - 当前所有数据都是 mock data（模拟数据）
> - 教师评价内容应经过审核后展示
> - 本项目不是匿名攻击平台，也不是教师排行榜

### Phase 1 已完成目标

- ✅ 快速验证产品原型和核心交互流程
- ✅ 跑通评价、审核、举报完整流程
- ✅ 验证权限控制逻辑
- ✅ 为 Phase 2 准备好前端架构

## 🎯 核心功能

### 已实现功能

1. **课程浏览系统**
   - 16 个科目分类（语文、数学、英语、物理、化学、政治、历史、地理、生物、体育、信息技术、音乐、美术、心理、综合实践、其他）
   - 课程列表按科目分类浏览
   - 课程详情展示课程信息、授课教师、已审核评价

2. **教师信息系统**
   - 教师列表浏览，显示评分摘要
   - 教师详情展示授课课程和学生评价
   - 写评价入口位于教师详情页

3. **评价提交系统**
   - 多维度评分（综合、难度、作业量、考试压力、清晰度、答疑、公平性、推荐度）
   - 标签选择 + 文本评价
   - 支持从教师详情页预选教师跳转
   - 提交后状态为 pending（待审核）

4. **我的评价**
   - 查看当前用户所有评价
   - 状态显示中文（待审核/已通过/已拒绝）
   - 支持删除自己的评价（软删除）

5. **后台管理**
   - 评价审核（通过/拒绝，拒绝需填写原因）
   - 举报处理
   - 教师/课程管理

6. **权限模拟**
   - 角色切换器：学生 / 审核员 / 管理员
   - 各角色权限隔离

## 📄 页面结构

```
/                              # 首页
├── /courses                   # 课程列表
│   └── /courses/[id]          # 课程详情
├── /teachers                  # 教师列表
│   └── /teachers/[id]         # 教师详情
├── /review/new                # 提交评价表单
├── /my-reviews                # 我的评价记录
└── /admin                     # 后台管理
    ├── /admin                 # 后台概览
    ├── /admin/reviews         # 评价审核
    ├── /admin/reports         # 举报处理
    ├── /admin/teachers        # 教师管理
    └── /admin/courses         # 课程管理
```

## 🔒 权限说明

| 角色 | 权限 |
|------|------|
| **学生** | 浏览评价、提交评价、举报评价、查看/删除自己的评价 |
| **审核员** | 审核评价、处理举报 |
| **管理员** | 全部权限 + 教师/课程管理 |

---

## ⚠️ 安全边界

本平台致力于构建健康的反馈环境：

- **非匿名攻击平台**：本平台不是匿名攻击教师的工具，评价需经过审核才能展示
- **非排行榜系统**：不做教师排行榜、红黑榜，专注于提供客观反馈参考
- **结构化反馈**：评价采用多维度评分+标签+文本形式，便于审核和参考
