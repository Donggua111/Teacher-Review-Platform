# 评价初中老师

初中教师与课程评价平台，让学生分享真实的学习体验。

## 项目定位

本项目是**教师/课程评价 Web 网站**，不是 App、小程序、桌面端或浏览器插件。

## 当前阶段：Phase 1 - 前端 Mock Web App

本项目目前处于**Phase 1：前端 Mock 版**，不接入任何后端服务，所有数据均为模拟数据。

Phase 1 不是最终目标，而是完整网站的第一阶段。当前阶段的目标是：
- 快速验证产品原型和核心交互流程
- 跑通评价、审核、举报完整流程
- 验证权限控制逻辑
- 为 Phase 2 准备好前端架构

## 最终目标

Phase 2/Phase 3 将实现完整 Web App，包括：
- 真实用户登录（Supabase Auth）
- 邀请码注册机制
- Supabase 真实数据库
- 真实审核流程和 RLS 权限控制
- 举报处理和通知机制
- 部署上线和小范围测试

## 技术栈

- **框架**: Next.js 14 (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **组件库**: shadcn/ui
- **图标**: Lucide React
- **状态管理**: React Context (store-context.tsx) + 兼容入口 (store.ts, store.tsx)
- **数据**: Mock Data (内存存储，刷新丢失)

## 如何运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

访问 http://localhost:3000

## 当前功能范围

### 已实现功能

- 首页：展示课程列表、教师列表入口
- 课程列表：按科目分类浏览课程
- 课程详情：查看课程信息及相关评价
- 教师列表：浏览所有教师
- 教师详情：查看教师信息及相关评价
- 提交评价：填写多维度评价表单
- 我的评价：查看当前用户的评价记录
- 后台管理：
  - 评价审核（approve/reject）
  - 举报处理
  - 教师/课程管理

### 权限模拟

通过页面右上角的用户切换器，可在三种角色间切换：

| 角色（内部值） | 显示文案 | 权限 |
|------|------|------|
| student | 学生 | 浏览评价、提交评价、举报评价 |
| moderator | 审核员 | 审核评价、处理举报 |
| admin | 管理员 | 全部权限 + 教师/课程管理 |

## 哪些功能只是 Mock

以下功能在本阶段仅为模拟，不代表最终产品行为：

| 功能 | 说明 |
|------|------|
| 用户系统 | 使用预设用户，无真实登录 |
| 数据存储 | 页面刷新后数据重置 |
| 评价提交 | 状态直接变为 pending，无真实发送 |
| 举报处理 | 仅改变状态，无真实通知 |
| 教师管理 | 仅切换 is_active 状态 |
| 课程管理 | 仅切换 is_active 状态 |
