# 评价初中老师

初中教师与课程评价平台，让学生分享真实的学习体验。

## 项目定位

本项目是**教师/课程评价 Web 网站**，不是 App、小程序、桌面端或浏览器插件。

## 当前阶段：Phase 1 - 前端 Mock Web App

本项目目前处于**Phase 1：前端 Mock 版**，**核心功能已完成并通过最终验收**。

Phase 1 不是最终目标，而是完整网站的第一阶段。当前阶段的目标是：
- ✅ 快速验证产品原型和核心交互流程
- ✅ 跑通评价、审核、举报完整流程
- ✅ 验证权限控制逻辑
- ✅ 为 Phase 2 准备好前端架构

## 最终目标

Phase 2/Phase 3 将实现完整 Web App，包括：
- 真实用户登录（Supabase Auth）
- 邀请码注册机制
- Supabase 真实数据库
- 真实审核流程和 RLS 权限控制
- 举报处理和通知机制
- 部署上线和小范围测试

## 技术栈

- **框架**: Next.js 14 (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **组件库**: shadcn/ui
- **图标**: Lucide React
- **状态管理**: React Context (store-context.tsx) + 兼容入口 (store.ts, store.tsx)
- **数据**: Mock Data (内存存储，刷新丢失)

## 如何运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

访问 http://localhost:3000

## 当前功能范围

### 已实现功能

- **首页**：展示平台介绍、课程/教师入口、科目浏览、平台规则
- **课程系统**：
  - 课程列表：按科目分类浏览，卡片不显示星级评分
  - 课程详情：查看课程信息、授课教师入口、已审核评价列表
  - 不在课程详情页提供写评价入口
- **教师系统**：
  - 教师列表：浏览所有教师，显示评分摘要
  - 教师详情：查看教师信息、授课课程、学生评价、写评价入口
  - 点击写评价自动跳转到 `/review/new?teacherId=xxx`
- **提交评价**：
  - 多维度评分（综合、难度、作业量、考试压力、清晰度、答疑、公平性、推荐度）
  - 标签选择、文本评价
  - 支持从教师详情页预选教师
  - 提交后状态为 pending（待审核）
- **我的评价**：
  - 查看当前用户所有评价
  - 状态显示中文（待审核/已通过/已拒绝）
  - 删除自己提交的评价（软删除）
- **后台管理**：
  - 评价审核（通过/拒绝，拒绝需填写原因）
  - 举报处理
  - 教师/课程管理
- **科目支持**：16 个科目（语文、数学、英语、物理、化学、政治、历史、地理、生物、体育、信息技术、音乐、美术、心理、综合实践、其他）
- **权限模拟**：角色切换器，支持学生/审核员/管理员三种角色

### 权限模拟

通过页面右上角的用户切换器，可在三种角色间切换：

| 角色（内部值） | 显示文案 | 权限 |
|------|------|------|
| student | 学生 | 浏览评价、提交评价、举报评价 |
| moderator | 审核员 | 审核评价、处理举报 |
| admin | 管理员 | 全部权限 + 教师/课程管理 |

## 哪些功能只是 Mock

以下功能在本阶段仅为模拟，不代表最终产品行为：

| 功能 | 说明 |
|------|------|
| 用户系统 | 使用预设用户，无真实登录 |
| 数据存储 | 页面刷新后数据重置 |
| 评价提交 | 状态直接变为 pending，无真实发送 |
| 举报处理 | 仅改变状态，无真实通知 |
| 教师管理 | 仅切换 is_active 状态 |
| 课程管理 | 仅切换 is_active 状态 |
